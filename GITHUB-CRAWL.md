# GitHub crawl: Total Recall
Measured 2026-11-07 from public GitHub data, read-only. Repo snapshots were downloaded to a temporary folder; nothing was forked, starred or commented on.

## Method and limits
- Code and repo search on the sponsor endpoints and SDK names gave 202 candidate repos. 39 remained after requiring a push since Oct 20 and a Walrus/MemWal mention.
- **33 of 39 mention Tatum or Total Recall in the README or description.** That is the closest estimate of the visible field. There is no public gallery, so private or unindexed entries are not counted.
- Columns count README mentions, not API call sites. The heat map below does scan the code.
- Commit counts were not collected.

- **precedent:** finished films, a proof page, a well-told correction story.

## Winners vs losers repo checklist
No past winner of a Tatum or Walrus Memory event has a published repo list that I could find. This list comes from `winning-patterns.md`, measured at other events:
- Public repo with a detected licence, work on main (16 of 39 rivals have a licence here).
- CI (11 of 39) and a reproduce command beside each number (21 of 39 have 10+ test files).
- Every claimed technology found by grep.
- A no-login judge path.
- A demo that stays up, a captioned gallery.
- No commits after the deadline.
